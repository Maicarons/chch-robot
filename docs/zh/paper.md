# 学术论文：面向中国象棋的人机对弈机器人系统设计与实现

本文档站点配套的学术论文，系统阐述 CH-RO 中国象棋对弈机器人：从视觉棋盘识别、Pikafish UCI
决策引擎，到 STM32 五值指令协议与机械臂执行，并以 Flask Web 界面贯通人机交互。论文使用
XeLaTeX + ctex 排版，参考文献采用 GB/T 7714-2015 格式，包含系统架构图、识别流水线、协议时序、
棋盘几何等矢量插图与多张真实数据表格，并嵌入实际部署中采集的棋盘图像。

## 内容概要

- **感知层**：RTMPose 四角关键点定位 + 透视校正，单一全局分类器一次性输出整盘 90 个交叉点类别（14 种棋子 + 空 / 未识别）；多帧稳定与基于中国象棋规则的动态走子推断。
- **认知层**：Pikafish（UCI\_Variant=xaingqi）走法决策，扩展 FEN 表示棋局。
- **执行层**：五值 ASCII 指令协议 `startX,startY,endX,endY,signal`（TCP 8086），STM32 下位机完成运动学解算与“STATE:5,RESULT:1”完成确认握手。
- **接口层**：Flask（端口 5000）提供实时视频、单步/连续识别、硬件与仿真双模式对弈。
